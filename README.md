# 豆包短剧创作工作台

[下载最新版本](https://github.com/lio1985/comicdesk-releases/releases/latest)

- 日常更新：选择 `ComicDesk-Update` 轻量升级包，约18MB，电脑需已有WebView2运行库。
- 首次安装或修复浏览器运行库：选择 `ComicDesk-Setup` 完整离线安装包，约232MB。

先安装一次v1.6.117。之后打开工作台会后台检查新版本，显示更新内容并引导下载和安装；升级助手等待工作台保存退出后再安装。也可在“更多工具 → 检查软件更新”手动检查。

此仓库用于发布安装包和版本信息，不存放用户作品、账号或登录资料。
